This page imports the class and registers it manually. Use invented details: localStorage keeps plaintext drafts on this device, readable by scripts on this origin. Passwords and files are excluded. Retention choices affect post-submit data, not consent to autosave.

Without JavaScript, or if the CDN module fails, the native form still works, but drafts aren’t saved. Keep a copy before leaving. The placeholder /demo-contact endpoint has no submission service.

Class-only import

Keep the module script with the form below. Its guard avoids registering the tag twice. Each demo uses a distinct storage key. Load feedback.js before registration to display the authored recovery message. 

<script src="./feedback.js" type="module"></script>
<script type="module">
  import { FormSaverElement } from
    'https://esm.sh/@aarongustafson/form-saver@1.1.0/form-saver.js?bundle&target=es2022';
  if (!customElements.get('form-saver')) {
    customElements.define('form-saver', FormSaverElement);
  }
</script>

<form-saver storage-key="demo:esm">
  <form action="/demo-contact" method="post">
    <label>Name <input name="name" autocomplete="name" /></label>
    <label>Email <input name="email" type="email" autocomplete="email" /></label>
    <button type="submit">Send</button>
  </form>
  <p class="draft-feedback" role="status"
    data-error="Draft storage is unavailable. Your entered values remain in the form. Keep a copy before leaving."></p>
</form-saver>
